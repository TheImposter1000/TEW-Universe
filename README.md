# TEW Universe Studio

TEW Universe Studio is an independent Windows desktop database editor for existing Total Extreme Wrestling IX scenario records.

The first milestone focuses on finding and editing existing workers in a separate working copy of a TEW IX `.mdb` scenario database. Later modules may support promotions, titles and history generation after validation.

The application is written in C# with .NET 8 Windows Forms. See `docs/DEVELOPMENT.md` for build and safety notes.

No TEW game files, database password, saves, or proprietary data are included or permitted in this repository.

Not affiliated with or endorsed by the makers of Total Extreme Wrestling.

The application header and Windows executable/installer icon use the approved TEW Universe Studio branding. The branding assets are stored in `src/TEWUniverse.Studio/Brand/`.
